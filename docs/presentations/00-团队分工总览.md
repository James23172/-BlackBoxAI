# BlackBoxAI — 5人团队分工总览

## 项目简介

**项目名称**：BlackBoxAI 分布式多机器人协同地图探索系统  
**技术栈**：Java 17 + Maven + Redis + RabbitMQ + WebSocket  
**核心功能**：4辆智能小车在40×40未知栅格地图上协同探索，通过黑板模式共享知识，实现100%地图覆盖  

## 团队分工矩阵

| 成员 | 角色 | 模块 | 类比 | 核心产出 |
|:--:|------|------|:--:|------|
| **P1** | 架构师 | `common` | 🏗️ 地基 | Redis黑板、RabbitMQ消息总线、分布式锁、一键启动器 |
| **P2** | 安全负责人 | `auth` | 🔐 门禁 | 四层加密体系、三级角色RBAC、Token认证 |
| **P3** | 调度负责人 | `controller` + `task-configurator` | 🧠 大脑 | 全局任务调度、地图初始化、增量小车管理 |
| **P4** | 算法负责人 | `navigator` + `target-planner` + `car` | 👁️ 眼睛+腿 | 路径规划(BFS/A*)、贪心目标选择、小车执行、避障 |
| **P5** | 全栈负责人 | `display` + `replay` | 🎨 脸面 | WebSocket实时推送、三面板前端、历史回放系统 |

## 消息流序列

```
P2           P5              P3                  P4
认证 ──→ 前端登录 ──→ TaskConfigurator ──→ TargetPlanner
                        │ 初始化地图+障碍物       │ 选择未探索目标
                        │ 网格分区出生点            │ ↓
                        ↓                        Navigator
                   Controller               BFS/A*路径规划
                      │ BLPOP消费                 │ ↓
                      │ 任务状态机                CarAgent
                      │ ────────NAVIGATE──────→ 执行移动+点亮
                      │ ←─────pushTask─────────
                      └ ──Fanout REFRESH_ALL ──→ Display → 浏览器
                                            (每200ms)
                  基础设施层 (P1) 全程提供 Redis/RabbitMQ/Lock 支持
```
